How to preview
1. Extract the ZIP.
2. Open index.html in a modern browser. For best results, use a local development server.
3. The site loads Bootstrap 5.3.3, Bootstrap Icons and Google Fonts from CDNs, so an internet connection is needed for those resources.

How to publish
Upload the complete folder contents to the web root of your hosting account (often public_html). Keep the folder structure intact. Point www.trillion-energies.com to that hosting account and enable HTTPS with your hosting provider.
